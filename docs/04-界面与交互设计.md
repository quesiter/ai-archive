## 1. 路由与信息架构

登录后的侧栏主导航依次为：

1. 总览 `/`
2. 会话 `/conversations`
3. 活动 `/activity`
4. 项目 `/projects`
5. 标签 `/tags`
6. 报告 `/reports`
7. 导入 `/imports`
8. 设备 `/devices`
9. 日志 `/logs`
10. 回收站 `/trash`
11. 设置 `/settings`

侧栏底部提供“更新记录” `/changelog`。会话详情 `/conversations/:id` 和报告详情 `/reports/:id` 由列表进入，不显示为主导航项。旧 `/classification` 重定向 `/projects`，未知地址重定向首页。

## 2. 登录、初始化与故障呈现

- 未初始化实例显示用户名、密码表单；用户名至少 3 字符，密码至少 12 字符。
- 初始化成功后只显示一次 TOTP Secret/URI；用户加入认证器后，用用户名、密码和 6 位验证码登录。
- `/auth/me` 返回 401 时才回到登录状态；网络故障显示“无法连接服务器”，5xx 显示服务端异常并提供重试，不再把故障伪装成退出登录。
- `bootstrap` 的校验错误保留 400，只有实例已经初始化才显示 409。

代码依据：`apps/web/src/App.tsx` 的 `AuthGate`；`apps/server/src/routes/auth.ts`。

## 3. 总览与归档可靠性中心

总览展示会话及完整性、项目/标签、文本量、来源上报与估算 Token、设备、近 7/30 日变化、活跃项目、采集健康和最近报告。Token 不是计费账单。

“需要处理”卡片调用 `/api/v1/reliability/summary`，分别显示：

- 不完整会话；
- 最近采集失败；
- 超过 24 小时仍未恢复的失败；
- 离线设备；
- failed/partial 导入。

每项提供到会话、日志、设备或导入页的定位入口。Dashboard 不自动轮询，重新进入或刷新后更新。

## 4. 会话列表、保存搜索和批量整理

筛选区包含关键词、平台、来源、完整性、采集方式、主项目、最多 20 个标签以及起止日期。标签为 AND；时间范围为起点包含、终点不包含。关键词中的 `%`、`_` 和反斜线按字面搜索。

服务端统一返回 `items + pagination(total/limit/offset/hasMore)`，Web 每页 100 条并使用公共 `Pagination`，不再用“满页猜测下一页”。关键词命中显示标题/正文原因、Revision ID、消息 ordinal 和摘要。

用户可将当前 URL 筛选（不保存 offset）命名为“常用视图”，以后从下拉框恢复；界面支持创建、应用和确认删除。

当前页可多选或全选，最多 500 个 ID 一次执行：设置/清空主项目、添加标签、移除标签、批量导出 CSV/Markdown/XLSX。没有批量永久删除。

## 5. 会话详情、Revision Diff 与回收站

详情页支持：

- 切换 Revision，查看采集时间、方式、完整性、来源设备、适配器和消息数；
- “与上一版本比较”，展示新增、修改、移除消息、历史标题和 canonical URL 变化；Migration 前 Revision 会明确提示历史元数据不可验证；
- 设置主项目或“交还 AI 调整”；
- 添加人工固定标签、交还 AI 管理、移除标签关系；
- CSV、Markdown、XLSX 导出，打开经过 HTTP(S) 校验的原链接；
- 移入回收站。

普通删除不物理移除。回收站按 50 条分页，显示删除时间，可恢复；永久删除必须输入精确大写 `DELETE`。超过 30 天的项目由 Worker 自动清理。

普通文本、代码和引用直接展示；推理与工具状态折叠，部分 system/tool 和内部运行时内容按显示规则隐藏。

## 6. 项目页

项目页包含统计、分页项目/未归类列表、整理任务状态、增量整理/完整重评、新建、编辑、归档、恢复、合并、项目导出、时间线和 Context。

- 项目名提交时由服务端执行 NFKC、trim 和连续空白折叠；空名或视觉重复会明确报错。
- 合并不可撤销；源项目关系和报告引用移动到目标项目后删除源项目。
- 时间线使用统一 total/limit/offset 分页，不再截断前 100 条。
- Context 弹出两种模式：“智能总结 + 历史索引（推荐）”和“仅历史索引（不使用 AI）”。AI 失败时提示是否生成基础版本。
- 归档项目仍可查看时间线、导出和 Context，但不能接收新人工归属。

## 7. 标签页与关系语义

标签页使用词云和选中详情布局，支持创建、本地搜索、查看关联会话、重命名、合并和删除。删除标签只删除标签及关系，不删除会话。

人工添加在界面显示“人工固定”。“交还 AI 管理”会真实把关系从 manual 转成 auto、解除锁定并清空人工置信度，然后触发单会话整理；这不再是只改锁标记的伪解锁。标签合并由后端事务和 advisory lock 保护。

## 8. 报告页

页面支持生成周报/月报、查看最近运行进度与错误、额度延迟续跑状态，以及分页浏览全部报告。运行中每 2.5 秒轮询。

报告详情按安全 Markdown 渲染，跳过原始 HTML，图片只显示替代文本，外链只允许 HTTP(S)。列表/详情可下载 Markdown，并显示邮件发送状态、时间、attempt和错误；失败项可重试。仍没有编辑或删除。SMTP 测试和自动发送开关在设置页。

## 9. 导入页

页面接受最大 512 MiB ZIP，支持 ChatGPT、Gemini Takeout 与 Chat Memo。导入记录统一分页，活跃任务每 2.5 秒刷新。

状态为 queued、processing、completed、partial、failed。partial 会明确显示已导入、未变化、失败和总数。failed/partial 行提供“重试”，相同 ZIP 再上传也会复用原任务重新入队，不需要修改文件。

页面可“清理过期文件”，或确认后“立即清理全部 ZIP”；操作只删 Processed/Failed 原文件，不删除已导入数据库记录。

## 10. 活动、设备与日志

活动页聚合后台整理任务、报告运行、导入和采集活动，显示运行中/失败/警告计数并分页。各项根据 `href` 跳往业务页或日志。

设备页可下载服务器 release 目录中的 Chrome、Windows、macOS 组件，为 Chrome 或本地同步代理生成配对码，查看、重命名、撤销和删除设备。列表显示客户端版本、OS、最近扫描/成功同步/错误和文件数；Adapter Health 按平台/版本展示24h/7d complete/partial/failed与健康状态。撤销不可恢复，只能重新配对。

Chrome Popup 另有“待上传”区，显示 Outbox 数量、会话、attempt、HTTP/错误和下次重试；可单条/全部重试或确认删除。401 时显示“设备授权已失效”，重新配对前不丢 Outbox。

日志页支持 1h/24h/7d/30d、自定义日期、scope、level、平台、设备、状态和关键词筛选，采用统一分页并轮询刷新。结束日期按下一日零点右开。

## 11. 设置页

二级导航为：

- 账号与安全：修改密码、两阶段重新绑定 TOTP、查看 Session、注销单个或其他浏览器 Session；新验证器确认前旧 TOTP 始终有效，pending 可取消/过期。
- 模型与额度：Base URL、API Key、模型、连接测试、节流、调用间隔、夜间维护。
- 项目与标签：新采集整理、项目变化重评、默认运行方式、稳定结果复用、正文上限。
- 邮件与报告：SMTP、测试邮件、周/月报告开关。
- 备份与恢复：下载一致性业务快照、只验证文件、上传异步恢复；显示 RestoreJob 阶段/进度/错误。替换前可取消；pre-commit failed可完整重试或删除暂存文件；post-commit recovery_required显示“继续恢复后处理”并保持维护模式。
- 脱敏与安全：安全规则包、自定义规则、测试、不可逆历史脱敏。
- 系统状态：应用、Worker、PostgreSQL、Host Monitor、容器资源、存储预算及 Inbox/Processed/Failed/Restore Staging 占用和保留期；提供归档完整性检查和全文索引重建。

API Key 和 SMTP 密码读取为掩码，保留掩码保存不会覆盖密文。恢复和历史脱敏都有危险操作确认。

## 12. 响应式、语言与已知 UI 边界

- 980px 以下侧栏、网格和设置布局收窄或改单列；680px 以下表单和操作纵向排列，表格横向滚动。
- 界面固定简体中文，没有语言切换或原生移动 App；服务端日期边界和周期使用实例 `TZ`，浏览器按实例时区显示。
- 报告仍没有编辑/删除；设备撤销没有恢复。
- Restore 上传已脱离恢复执行，但 Worker 内部仍受压缩512MiB/解压1GiB及进程内存约束。

代码依据：`apps/web/src/App.tsx` 的 `navigation`、`Pagination`、`Dashboard`、`Conversations`、`ConversationDetail`、`Projects`、`Imports`、`ActivityPage`、`Trash`、`AccountSecurity` 和 `SystemStatus`。
