# 知言归藏 V2.1 UI 设计

## 1. 信息架构

侧栏主导航：

1. 总览
2. 会话
3. 项目与标签
4. 报告
5. 导入
6. 设备
7. 日志
8. 设置

“更新记录”继续位于侧栏底部。旧 /classification 地址重定向到 /projects。

## 2. 视觉原则

Web 延续浅色、低噪声和高信息密度布局。状态使用文字与轻量 pill 双重表达，不只依赖颜色。长标题、URL 和摘要允许换行或省略；重要操作在移动宽度下变为单列或可换行。

## 3. 总览

顶部指标显示总会话、总项目、已归类、未归类、标签数、文本量、估算 Token 和活跃设备。正文区域显示最近活跃项目、近 7/30 日变化、常见标签、近 24 小时采集健康和最近报告。

“归档可复用状态”解释标签与项目如何帮助搜索和导出，不展示旧派生统计。

## 4. 会话列表

工具栏保留关键词、平台、来源、完整性、Capture Mode、时间和分页，并增加：

- 主项目下拉筛选。
- 标签复选浮层，可同时选择多个标签，采用 AND 组合。
- 清除筛选和结果数量。

每条结果显示标题、平台、捕获时间、项目、标签和完整性。搜索命中额外显示“标题命中”或“正文命中”及附近摘要。点击正文命中打开指定 Revision，并滚动到带 message ordinal 的锚点。

## 5. 会话详情

顶部工具栏包含 Revision 选择与主项目选择。人工选择后项目被锁定，可点击“交还 AI 调整”解锁。

标签面板支持搜索或选择标签后新增；人工关联默认锁定。每个标签显示来源/锁定状态，并提供锁定切换、删除和按该标签查看会话的入口。消息正文和原始导出保持不变。

## 6. 项目与标签

顶部四项统计：项目数、已归类、未归类、标签数。

项目区域展示：

- 名称与描述。
- 会话数量、最近活动、近 7/30 日新增。
- 常见标签。
- 会话清单与项目时间线。
- CSV、Markdown、XLSX 原始会话导出。
- PROJECT-CONTEXT.md 生成与下载。
- 编辑、合并和归档操作；已归档项目单列显示并支持恢复。

时间线按日期、平台、标题、标签展示，每项打开原始会话。

标签管理区支持搜索、创建、重命名、合并、删除和查看关联会话数量。删除操作明确提示只移除标签关联，不删除会话。

自动整理进度仍可在本页查看，但页面主体表达用户的组织结果，不把后台任务当作信息架构名称。

## 7. 报告

报告页保留周报、月报列表、手动生成、状态与邮件入口。统计使用会话、项目和标签数量。报告正文按 Markdown 显示，并链接相关归档来源。

## 8. 设置与任务状态

“项目与标签”设置区控制采集后自动整理、项目变更后自动重评、节能/完整模式和稳定结果复用。AI 额度暂停显示刷新窗口、预计续跑时间和倒计时，不能伪装成普通失败。

用户主动生成 Context 时显示独立 loading/error 状态；该请求使用交互优先级，不加入批量固定等待。

## 9. 响应式

- 980px 以下侧栏收窄、主要网格改单列。
- 680px 以下筛选器、表单、项目行、会话卡片和标题操作纵向排列。
- 标签选择浮层宽度不超过视口，列表可滚动。
- 时间线从日期/内容双列变为单列。
- 表格保留横向滚动，不裁掉操作。
- 不提供独立移动端功能，现有 Web 只保证可读、可检索和可操作。
