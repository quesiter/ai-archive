# 界面设计文档

## 1. 文档范围

本文描述服务端、Web 与客户端 `V2.0.0` 已实现的用户界面：Web 管理后台、Chrome 插件弹窗与网页悬浮状态窗、Windows/macOS 本地同步入口。它记录当前信息架构、状态、交互和响应式行为，不包含尚未实现的原型。

产品名称为“知言归藏”，标语为“汇智能之言，成项目之知。”；英文包名和 `ai-archive` 路径仅作为兼容性标识保留。

## 2. 视觉与布局基础

Web 使用浅灰页面背景、白色内容面板和深色固定侧栏。主要设计变量来自 `apps/web/src/styles.css`：

| 用途 | 当前值或表现 |
| --- | --- |
| 字体 | Inter、SF Pro Display、苹方、微软雅黑、系统字体回退。 |
| 主文字 | `#18252f`。 |
| 次要文字 | `#667887`。 |
| 主操作色 | `#0f766e`。 |
| 危险操作 | 玫红色；用于永久删除、撤销和替换数据。 |
| 面板 | 白底、1px 低对比边框、轻阴影、8px 圆角。 |
| 最小视口 | 320px。 |

桌面端为 248px 侧栏加弹性内容区；内容最大宽度 1580px。视口小于 980px 时侧栏收缩为 76px，隐藏品牌文案与非活动导航文字，多列区域逐步改为一列或两列。

## 3. 登录与全局框架

### 3.1 首次初始化与登录

未登录时展示居中的品牌卡片：知言归藏、标语和“知”字标记。

- 未初始化：显示用户名和至少 12 位密码输入，创建唯一管理员；成功后显示 TOTP Secret 与 OTP URI。
- 已初始化：显示用户名、密码和 6 位 TOTP 输入。
- 认证错误在卡片内以错误提示展示；敏感字段使用密码输入控件。

### 3.2 登录后框架

侧栏顶部展示“知言归藏”和标语，底部展示系统版本 `V2.0.0`、小型“更新记录”入口与退出按钮。主导航为：总览、会话、分类结果、项目知识、报告、导入、设备、日志、设置；更新记录不占用主导航项。

“更新记录”是独立页面，依据 Git 与发布记录按时间倒序显示版本号、发布日期、版本主题和逐项变更；当前版本区域同时说明后续 `V2.0.x` 补丁号规则。

全局状态语义：

| 状态 | 中文显示 | 视觉语义 |
| --- | --- | --- |
| `queued` | 已入队 | 等待/琥珀。 |
| `running`、`processing` | 运行中、处理中 | 进行中。 |
| `completed`、`complete`、`active` | 已完成、完整、有效 | 成功/绿色。 |
| `partial` | 不完整 | 警告。 |
| `failed`、`revoked`、`deleted` | 失败、已撤销、已删除 | 危险/红色。 |

Token Plan 暂停不是普通失败：归类、知识和报告进度区域会显示额度窗口、预计续跑时间及动态倒计时。

## 4. Web 页面

### 4.1 总览 `/`

显示总会话、总项目、已归类/未归类会话、文本量、估算 token 和知识条目。分类分布最多展示前 12 个项目及会话量、近 7 日增长和知识数；同时展示知识产生说明、近 24 小时各平台完整/不完整/失败采集数量和最近报告入口。

### 4.2 会话 `/conversations`

紧凑列表支持：

- 关键字正文/标题搜索；正文命中展示摘要和消息序号。
- 平台、来源（网页、OpenClaw、Codex、Claude Code、历史导入）、时间、完整性和采集模式过滤。
- 分页、平台 Session 数、项目归属、置信度、来源设备、最新同步时间和消息数展示。

### 4.3 会话详情 `/conversations/:id`

顶部提供 CSV、Markdown、XLSX 导出和永久删除。版本列表按采集时间、修订创建时间稳定排序；默认选择优先使用完整修订，再以采集时间和创建时间判断新旧。相同采集时间时仍选择最新写入修订，避免 Codex 后续答案被旧修订遮挡。

详情展示项目绑定（人工锁定或 AI 动态调整）、采集模式、触发原因、来源设备、适配器、完整性和采集时间。消息按用户、助手、系统、工具和未知角色区分；URL 查询参数可指定修订，消息锚点用于从知识依据跳转。

### 4.4 分类结果 `/classification`

提供项目创建与编辑、项目归档、节能增量归类、完整重评、任务进度、项目 A 合并到项目 B、项目 CSV/Markdown/XLSX 导出。分类结果按项目折叠展示会话、人工锁定和置信度；空项目单独归组；待归类区展示建议项目名。

项目合并为危险操作：会迁移源项目的会话、知识和相关报告，然后删除源项目，提交前浏览器确认。

### 4.5 项目知识 `/knowledge`

页面先显示结论、知识定义和统计，再展示知识重建任务进度。知识仅列出 `active` 条目，可按项目、类型及标题/正文关键字过滤。

知识卡包含类型、更新时间、标题、中文正文、置信度和原始依据；每个依据链接到对应会话、修订和消息序号。页面明确区分长期有效知识与不应沉淀的实施过程、工具播报、临时状态和无证据猜测。

### 4.6 报告 `/reports` 与 `/reports/:id`

报告页可立即生成周报或月报，生成状态分别只取最新一条周报运行和最新一条月报运行。状态卡显示阶段、进度、处理数量、错误或额度等待信息。报告列表展示准确周期；周报周期为上一完整周一至周日，月报为上一自然月。

详情页显示标题、准确周期、摘要和 Markdown 正文。Markdown 禁止原始 HTML；外链只允许安全的 HTTP/HTTPS 地址并在新窗口打开，图片只显示替代文字。

### 4.7 导入 `/imports`

上传 ZIP 后异步处理，页面显示最近 100 条导入任务、来源、状态、进度、统计和错误，并可手动刷新。当前界面说明 ChatGPT 与 Gemini；服务端同时识别已实现的 Chat Memo 多平台 ZIP。

### 4.8 设备 `/devices`

顶部从服务端发布目录发现并下载 Chrome、Windows、macOS 组件，显示版本、大小和是否可用。配对区生成有时效的一次性码，设备类型为 Chrome 扩展或 OpenClaw/Codex 同步代理。设备列表支持重命名；活动设备首次点击为撤销，已撤销设备再次点击为删除。

### 4.9 日志 `/logs`

以紧凑表格显示时间、范围、等级、平台、状态、对象和消息。支持范围、等级、平台、状态和关键字过滤；平台下拉显示 Session 数。元数据默认折叠，页面每 5 秒刷新，同时保留手动刷新。

### 4.10 设置 `/settings`

设置页使用“左侧二级菜单 + 右侧当前设置面板”的结构；窄屏时二级菜单转为页面顶部网格。当前已实现区域为：

1. OpenAI 兼容接口：Base URL、API Key、模型名与连接测试。
2. 智能归类：采集后自动归类、项目变更后重归类、节能/完整模式、稳定结果复用、最大输入字符数。
3. Token Plan 共享调度：全局节流开关、最小调用间隔、每天 22:00 夜间维护开关。
4. 报告邮件：SMTP 主机、端口、安全连接、账号、密码、发件人、收件人、周报/月报开关。
5. 备份恢复：下载业务备份；上传备份并替换业务数据，提交前确认。
6. 脱敏：新增/启停/删除自定义正则；一键启用安全规则包；手动启动历史清理；查看清理进度；预览入库或发往 AI 前效果。
7. 系统状态：显示应用、容器监测和 PostgreSQL 可用性；汇总本项目容器的 CPU、内存、Swap 与最近 27 个 CPU/内存采样点；项目存储显示数据库与导入文件的实际用量，只有设置软预算时才出现百分比和容量告警；同时显示数据库连接数、活跃连接、最长查询和 Web 备份记录。页面每 10 秒自动刷新并支持手动刷新。

API Key 与 SMTP 密码读取时只显示 `********`；保存掩码不会覆盖现有秘密。规则测试使用虚构示例，文本不保存、不发送给模型。

## 5. Chrome 插件界面

插件名称与工具栏标题为“知言归藏”，版本 `V2.0.0`。

未配对时，弹窗显示固化的服务地址和配对码输入；配对时请求归档服务与支持平台的 host 权限。已配对后显示当前页面、Session、最近状态、完整/增量模式与时间，并提供重新完整采集、暂停/恢复本站、隐藏/显示浮窗和重试上传。

网页悬浮窗使用“知”字按钮和状态点，展开后显示平台、状态、原因、模式、消息数、上次同步、重新采集和暂停操作。状态包括待机、检查变化、等待生成、内容未变化、正在采集、等待上传、正在同步、完整归档、不完整和失败。

## 6. 本地同步客户端界面

Windows 提供批处理入口和隐藏计划任务；macOS 提供 `.command` 菜单和 LaunchAgent。终端标题统一为“知言归藏本地同步”，显示客户端版本、服务端版本握手、安全扫描范围、逐文件同步/跳过/失败信息。

配对需要服务地址和一次性码；默认配置、状态和日志路径见 Windows/macOS 专项文档。后台同步没有独立图形界面，运行状态在本地日志、Web 设备页、会话来源设备和操作日志中体现。

## 7. 破坏性操作与可访问性

- 永久删除会话、项目合并、撤销/删除设备、导入备份替换数据均使用危险样式并要求确认。
- 表单字段使用可见标签；关键筛选控件提供 `aria-label`；状态不仅依赖颜色，同时显示文字。
- 交互按钮存在禁用态；异步操作显示加载、进度、成功或错误提示。
- 响应式布局保留所有核心操作，不通过移动端隐藏业务功能。
