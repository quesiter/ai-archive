## 1. 认证、同源与统一响应

| 身份 | 认证方式 | 可访问范围 |
| --- | --- | --- |
| 公开 | 无 | `/healthz`、auth status/bootstrap/login、devices claim |
| Web 管理员 | `archive_session` HttpOnly Cookie | 除设备采集外的全部管理 API |
| 设备 | `Authorization: Bearer <token>` | `POST /captures`、`POST /devices/heartbeat` |

Web 的 POST/PUT/PATCH/DELETE 除 Cookie 外要求 `Origin` 或 `Referer` 与 `APP_ORIGIN` 一致，并拒绝 cross-site。动态响应为 `Cache-Control: no-store`。

分页接口统一返回：

```json
{
  "items": [],
  "pagination": {
    "total": 13842,
    "limit": 100,
    "offset": 200,
    "hasMore": true
  }
}
```

常见状态：400 输入错误；401 Session/Token 无效；403 不同源；404 不存在；409 状态或唯一性冲突；410 暂存文件已删除；429 限流；503 任务未能入队或恢复维护中；500 未映射故障。非法 UUID 返回 400。恢复进入 restoring/rebuilding_search/verifying/recovery_required 时，除认证、恢复进度和系统状态等允许入口外返回503及 `Retry-After`。

## 2. 健康、初始化与账号安全

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |

| GET | `/auth/status` | 公开 | 是否已初始化 |
| POST | `/auth/bootstrap` | 公开+同源，3 次/15 分钟 | username 3–64、password 12–256；首次创建并返回 TOTP Secret/URI；重复 409 |

| POST | `/auth/logout` | Web+同源 | 删除当前 Session，204 |
| POST | `/auth/password` | Web+同源 | 当前密码、当前 6 位 TOTP、新密码 12–256 |
| POST | `/auth/totp/reset` | Web+同源 | 当前密码和旧TOTP；创建约10分钟 pending Secret并返回URI，旧Secret仍有效 |
| POST | `/auth/totp/confirm` | Web+同源 | 用新验证器6位码确认并原子切换 |
| DELETE | `/auth/totp/pending` | Web+同源 | 取消pending，204；不影响旧Secret |

## 4. 采集

`POST /captures` 是设备 Bearer 接口，接受完整/import `CaptureSnapshotV1` 或 append `IncrementalCaptureV1`。

主要限制：12 个 Provider；sessionId 1–1,024；title ≤2,048；adapterVersion 1–64；HTTP(S) URL ≤8,192；完整消息 1–100,000；append 消息 0–10,000；每消息 Segment 1–10,000；单 Segment 1–2,000,000；可选 `Idempotency-Key` ≤512。

新 Revision 返回 201，重复/未变化返回 200。append 基线不匹配返回 409、`error=incremental_base_mismatch` 和 `requiresFullCapture=true`。解析失败 400 并尽量写失败 CaptureRun。归档成功后分类入队失败不回滚事实数据。

## 5. 会话、全文搜索、Diff、回收站和批量操作

### 5.1 列表与详情

`GET /conversations` 参数：

| 参数 | 规则 |
| --- | --- |
| `q` | 标题/完整正文，≤500；SQL 通配字符按字面 |
| `provider` | Provider 枚举 |
| `source` | web/openclaw/codex/claude_code/historical_import |
| `completeness` | complete/partial |
| `captureMode` | full/append/import |
| `projectId` | UUID |
| `tagIds` | 逗号或数组，最多 20 个 UUID，AND |
| `from` / `to` | 带偏移 ISO datetime；from 含、to 不含 |
| `limit` / `offset` | 默认 50/0；limit 1–200 |

返回分页 envelope。正文命中含 reason、revisionId、messageOrdinal、excerpt。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/conversations/provider-counts` | 活跃会话按 Provider 统计 |
| GET | `/conversations/:id?revisionId=` | 活跃会话、全部 Revision、选中版物化消息、项目和标签 |
| GET | `/conversations/:id/revisions/:revisionId/diff?baseRevisionId=` | 默认与上一版比较，也可指定同会话基线 |
| GET | `/conversations/:id/export?format=csv|md|xlsx` | 单会话原始导出 |
| DELETE | `/conversations/:id` | 软删除并进入回收站，204 |
| GET | `/conversations/trash?limit=&offset=` | 回收站分页，另返 retentionDays=30 |
| POST | `/conversations/:id/restore` | 恢复软删除会话 |
| DELETE | `/conversations/:id/permanent` | 仅回收站记录；body `{confirmation:"DELETE"}`；204 |
| POST | `/search/rebuild` | 从 Message/Segment 重建全文分块，返回 chunkCount；设置页有入口 |

### 5.2 批量操作

每次 `conversationIds` 为 1–500 个 UUID，只作用于仍活跃且存在的记录：

| 方法 | 路径 | 输入/结果 |
| --- | --- | --- |
| POST | `/conversations/batch/project` | `{conversationIds, projectId:UUID|null}`；项目必须未归档；人工锁定并清 stale 建议 |

## 10. 历史 ZIP 导入

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/imports?limit=&offset=` | 默认 50，最大 200；分页，并恢复僵尸任务 |
| POST | `/imports` | ZIP≤512 MiB；新任务 202；正常重复 200；failed/partial 同 hash 重新入队 202 |
| POST | `/imports/:id/retry` | 只允许 failed/partial；失败目录中 ZIP 不存在返回 409；成功 202 |
| POST | `/imports/cleanup` | `{scope:processed|failed|all, includeUnexpired:boolean}`；返回删除文件数/字节 |

支持 ChatGPT、Gemini 和 Chat Memo。整个 ZIP 不是单事务；partial/failed 之前的成功快照保留。入队 null 返回 503，不留下 queued 幽灵状态。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/backups/export` | 单个 REPEATABLE READ 只读快照内流式 gzip JSON，18 张表 |
| POST | `/backups/verify` | 只验证gzip/format/schema/18表/引用/Delta/计数/主密钥指纹；不写数据库 |
| POST | `/backups/import` | gzip JSON；HTTP流式写共享staging；成功入队返回202和restoreJobId |

## 14. 明确没有的接口能力

当前没有：多用户/角色/租户、忘记密码邮件自助重置、批量永久删除、报告编辑/删除、项目直接删除、设备撤销恢复、Webhook、通知、短信、对象存储、支付/套餐、任务/日历或内置 AI 对话。服务器侧管理员恢复是本地CLI，不是HTTP接口。

代码依据：`apps/server/src/app.ts` 的路由注册；`apps/server/src/routes/*.ts`；`apps/server/src/services/auth.ts`、`backup.ts`、`restore.ts`、`archive-integrity.ts`、`capture.ts`、`revision-diff.ts`、`search-chunks.ts`、`tag-merge.ts`。
